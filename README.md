# SQL Table Extractor for Logs
A lightweight, 100% client-side utility designed to scan raw application logs, text files, or console dumps, detect structured SQL result tables, and extract them into clean, exportable formats.

## 🚀 Features
* **Zero Installation:** Runs entirely in your web browser via simple CDN links—no build step or backend servers required.
* **Automated Log Parsing:** Paste unformatted log dumps containing query result grids or database text outputs, and the tool strips away log noise to isolate the table.
* **Instant CSV Export:** Download your extracted database rows straight to a local `.csv` file with a single click.
